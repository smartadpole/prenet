# 开集识别评估器技术文档

## 概述

本文档描述 `tools/eval_open.py` 的技术实现细节，面向开发者和维护者。该工具实现了基于离线特征库的度量学习开集识别方案，将模型从分类器任务转变为度量学习任务。

## 架构设计

### 模块结构

```
eval_open.py
├── OpenSetEvaluator 类
│   ├── 模型加载模块
│   │   └── _load_model()
│   ├── 特征库构建模块
│   │   ├── build_gallery()
│   │   └── _remove_outliers()
│   ├── 开集识别模块
│   │   ├── identify()
│   │   └── _weighted_voting()
│   └── 评估模块
│       └── run_eval()
└── 主程序
    └── main()
```

### 数据流

```
模板文件 → build_gallery() → 特征库 (gallery_features, gallery_labels)
    ↓
测试文件 → identify() → Top-K 检索 → 加权投票 → 阈值判定 → 预测结果
    ↓
run_eval() → 批量评估 → 准确率统计 → 结果输出
```

## 核心功能实现

### 1. 模型加载 (`_load_model`)

**职责：** 从检查点文件加载 DinoV2Embedder 模型（仅特征提取器，不使用 ArcFaceHead）

**实现细节：**
- 使用 `torch.load()` 加载检查点
- 从检查点的 `args` 字典中提取模型参数：
  - `backbone`：DINOv2 骨干网络（默认 "dinov2_vitb14"）
  - `embed_dim`：嵌入维度（默认 256）
  - `img_size`：图像尺寸（默认 128）
- 创建 `DinoV2Embedder` 实例并加载权重
- 设置为评估模式（`eval()`）

**设计决策：**
- 仅加载 `embedder` 权重，不加载 `head` 权重，因为开集识别不需要分类层
- 复用训练脚本中的模型定义，确保特征提取一致性

### 2. 特征库构建 (`build_gallery`)

**职责：** 从模板图构建离线特征库

**实现流程：**
1. 加载模板文件（格式：`image_path label_id class_name`）
2. 对每个模板图提取特征向量
3. 按类别分组特征
4. 对每个类别进行离群点清洗
5. 合并所有有效特征构建特征库

**关键参数：**
- `outlier_threshold`：离群点判定阈值（默认 2.0 倍标准差）

**设计决策：**
- 使用离线特征库而非可学习的特征中心，实现"即插即用"的识别
- 支持离群点清洗，确保模板特征纯净
- 统计每个类别的样本数量，用于后续的类别不均衡处理

### 3. 离群点清洗 (`_remove_outliers`)

**职责：** 从类别特征中移除异常样本

**算法：**
1. 计算该类所有特征的均值（L2 归一化后）
2. 计算每个特征到均值的余弦距离：`distance = 1 - cosine_similarity`
3. 计算距离的均值和标准差
4. 过滤距离超过 `mean + threshold * std` 的样本

**设计决策：**
- 使用余弦距离而非欧氏距离，因为特征已 L2 归一化
- 基于统计方法（均值 + 倍数标准差）而非固定阈值，适应不同类别的分布差异
- 如果标准差过小（< 1e-6），保留所有样本，避免过度过滤

### 4. 开集识别 (`identify`)

**职责：** 对查询图像进行开集识别

**实现流程：**
1. 提取查询图像的特征向量（L2 归一化）
2. 计算与特征库中所有样本的余弦相似度（点积）
3. 获取 Top-K 最近邻
4. 使用加权投票机制聚合类别得分
5. 应用双阈值判定：
   - 绝对阈值：最高相似度必须 > `threshold`
   - 相对阈值：Top-1 与 Top-2 得分差值必须 > `margin_threshold`

**关键参数：**
- `top_k`：最近邻数量（默认 5）
- `threshold`：绝对相似度阈值（默认 0.6）
- `margin_threshold`：相对增益阈值（默认 0.1）

**设计决策：**
- 使用 Top-K 检索而非全量比较，提高计算效率
- 双阈值判定机制，既考虑绝对置信度，也考虑类别间的区分度
- 如果最高相似度低于阈值或类别间区分度不足，判定为"未知类"

### 5. 加权投票机制 (`_weighted_voting`)

**职责：** 聚合 Top-K 最近邻的类别得分，处理类别不均衡问题

**得分计算公式：**

```
Score(c) = Σ (similarity_i × rank_weight_i × size_weight_c)
```

其中：
- `similarity_i`：第 i 个近邻的相似度
- `rank_weight_i = 1 / (rank + 1)`：排名权重（排名越靠前权重越大）
- `size_weight_c = 1 / log(N_c + 1)`：类别大小归一化权重（类别样本越多权重越小）

**设计决策：**
- **相似度权重**：距离越近的样本贡献越大
- **排名权重**：使用逆排名权重，让 Top-1 的贡献最大，Top-K 的贡献最小
- **类别大小归一化**：使用对数归一化，缓解样本量多的类别产生的压制效应
- 相比简单投票，这种方式让距离更近的模板拥有更大话语权，即使某类别模板较少，只要其中一个模板与测试图极其相似，该类仍能胜出

### 6. 评估流程 (`run_eval`)

**职责：** 批量评估测试集并统计结果

**实现流程：**
1. 加载测试文件
2. 对每个测试样本调用 `identify()` 进行识别
3. 统计预测结果（将 -1 视为 None 以兼容 `calculate_metrics`）
4. 计算总体和分类别准确率
5. 统计未知类判定数量
6. 输出详细结果到文件

**输出内容：**
- 总体准确率、正确数、错误数、总数
- 未知类判定数量
- 分类别准确率统计
- 每个样本的详细结果（路径、真实标签、预测标签、置信度、是否正确、是否未知）

## 技术对比

### 闭集 vs 开集方案

| **维度** | **闭集方案 (eval.py)** | **开集方案 (eval_open.py)** |
| --- | --- | --- |
| **决策方式** | ArcFaceHead 分类层 | Top-K 最近邻检索 + 加权投票 |
| **特征中心** | 可学习的权重矩阵 W | 离线计算的模板特征库 |
| **类别限制** | 固定数量（训练时确定） | 理论上无上限（可动态添加） |
| **灵活性** | 增加类别需重新训练 | 仅需提取新图特征存入数据库 |
| **样本依赖** | 依赖训练样本的分布均衡 | 能够处理极少样本（Few-shot）识别 |
| **计算开销** | 线性分类层，速度极快 | 需进行向量检索（样本多时需用索引加速） |

- `--outlier_threshold`：离群点判定阈值（默认：2.0）

## 设计决策与原理

### 为什么使用离线特征库？

1. **灵活性**：无需重新训练即可添加新类别
2. **可解释性**：特征库中的每个样本都是真实的模板图，便于理解和调试
3. **Few-shot 学习**：能够处理样本极少的类别识别任务

### 为什么使用加权投票而非简单投票？

1. **相似度权重**：距离更近的样本更可靠
2. **排名权重**：Top-1 的贡献应该最大
3. **类别大小归一化**：防止样本量多的类别压制样本量少的类别

### 为什么使用双阈值判定？

1. **绝对阈值**：确保识别结果有足够的置信度
2. **相对阈值**：确保类别间有足够的区分度，避免模糊样本被错误分类

## 未来改进方向

1. **特征索引优化**：当特征库样本数量很大时，使用 FAISS 等向量索引库加速检索
2. **多质心支持**：对于视角差异巨大的类别，使用 K-Means 聚类生成多个子中心
3. **动态阈值调整**：根据特征库的分布自动调整阈值参数
4. **特征库增量更新**：支持动态添加新类别模板，无需重建整个特征库
5. **可视化功能**：添加特征空间可视化，展示查询样本与模板的相似度分布
